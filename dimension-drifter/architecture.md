# Game Architecture: Dimension Drifter: The Magic Labyrinth
## Core Concepts
* The game is called "Dimension Drifter: The Magic Labyrinth".
* The gameplay takes place on a top-down grid maze.
* The main character is a smiling, bouncing marshmallow blob.
* The exit is a pile of star-shaped candies.
## Mechanics
* The player uses two sets of Magic Runes to toggle reality and solve puzzles.
* The first rune alters the State of Matter, turning an impassable Chocolate River into a solid candy bridge.
* The second rune alters the State of Behavior, shrinking giant Lollipop Guards into tiny, passable candies.
* Cursor Pro will scaffold the grid-based game loop and handle the 2D image swap logic.
